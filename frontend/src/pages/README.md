# Frontend Pages

Page components for different routes.

## Available Pages

### HomePage (App.jsx)
Landing page with feature overview
- Navigation header
- Hero section
- Feature cards
- Call-to-action

### LoginPage
User login form
- Email and password inputs
- Form validation
- Error handling
- Link to signup

### SignupPage
User registration form
- Full name, email, password inputs
- Password confirmation
- Form validation
- Auto-login after signup
- Link to login

### DashboardPage
User dashboard (protected route)
- User profile info
- Feature overview cards
- Logout button

## Adding New Pages

1. Create a new `.jsx` file in this directory
2. Use reusable components and utilities
3. Add route to `AppRouter.jsx`
4. Document in this README
