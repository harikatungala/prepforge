# 🚀 PrepForge - AI-Powered Interview Preparation Platform

**PrepForge** is an intelligent interview preparation platform that helps users ace their job interviews through AI-powered mock interviews, resume analysis, and personalized feedback.

## 📌 Project Overview

PrepForge combines three core features:

1. **Resume Analyzer** - AI analyzes your resume and provides ATS scores, improvement suggestions, and keyword recommendations
2. **AI Mock Interviews** - Practice real interview scenarios with an AI HR interviewer that evaluates your responses
3. **Progress Dashboard** - Track your preparation journey with statistics, achievements, and personalized recommendations

## 🎯 Tech Stack

### Frontend
- **React 18** - UI framework
- **Vite** - Build tool & dev server
- **Tailwind CSS** - Styling
- **Axios** - HTTP client
- **React Router** - Navigation

### Backend
- **FastAPI** - Web framework
- **PostgreSQL** - Database
- **SQLAlchemy** - ORM
- **Pydantic** - Data validation
- **JWT** - Authentication
- **OpenAI API** - AI integration

### Infrastructure
- **Vercel** - Frontend hosting
- **Render/Railway** - Backend hosting
- **PostgreSQL** - Database hosting

This project is built incrementally in phases. Each phase teaches full-stack concepts:

- **Phase 1** - Project setup and infrastructure
- **Phase 2** - Authentication (backend & frontend)
- **Phase 3** - Resume analyzer
- **Phase 4** - AI mock interviews
- **Phase 5** - Dashboard & analytics
- **Phase 6** - Testing & deployment
